# 词序微信小程序

0.5.6 将辨义抽测从9个核心学习日扩展到全部51个学习日。42个高频学习日逐日增加经过校对的多义词题，每个入选词同样提供两种语境并按自然日轮换；一句话自然包含两个目标词时会复用于两道题，但每道题只考一个词，绝不为压缩题库生硬拼接。自动测试会逐日检查核心与高频题目覆盖，防止后续再次漏掉高频词表。

0.5.5 扩充并轮换辨义抽测：题库由 12 句增加到 72 句，覆盖 9 个核心学习日；每个抽测词至少有两种语境，每个自然日轮换句子。关联记忆在拆解助记之外恢复少量经过筛选的高价值短语；`migrate`、`emigrate` 与 `immigrate` 按“中性迁移 / 移出 / 移入”及 e=exit、im=in 区分方向。

0.5.4 扩大发音操作热区：学习卡片中的播放事件由小播放图标移动到整个“播放图标＋音标”胶囊框，更容易单手点按；增加界面结构测试，防止后续改版把热区再次缩回图标。

0.5.3 全量发布：2522 条词汇已全部通过逐词助记门禁。每条助记都逐字覆盖目标拼写，并优先使用可靠构词、词族辨形、字母形状或读音，把单词直接牵回中文义；不再发布短语复述、无关场景或未审核兜底内容。

0.5.2 阶段发布：9 个核心学习日的全部单词均已按“拼写或读音直接牵回词义”的标准重写关联记忆，不再用短语复述或无关场景充数；同步发布已完成审核的高频 day 1。其余高频学习日继续逐词人工重写，未审核旧内容不会被标成新版助记。

0.5.1 提高关联记忆的验收标准：助记必须把字母、读音或可靠词形与含义连接起来，不能只换一种说法复述释义。`dilemma` 使用 `di-` 和双 `mm` 建立“两难”与拼写的回忆链；`deliberate` 使用 `liber` → `Libra（天秤座）` → 权衡的字形画面。关联中引用的其他词库单词会自动补充标准中文义，人工引入的专有联想词使用校对释义。

0.5.0 全量重建关联记忆：不再用单一规则或自动挑选字形接近的词硬做关联。每个词按“人工主钩子、可靠构词、已核对辨析、词族、短语块”依次选择记忆路径；没有可靠拆法时不冒充词根。核心第3天增加逐词画面、动作、熟词与声音钩子，`deteriorate` 使用“地铁里又热→环境恶化”的声音画面，`desperate` 和 `drawback` 使用可解释的构词与动作联系。

0.4.1 重新整理学习卡片的机构释义区：词性与标签合并为左侧单行，易忘状态靠右，主释义左对齐。撤销长词机械等分和自动复合词猜测；`device` 不再拆成 `dev·ice`，只与动词 `devise` 做词性及 c/s 拼写辨析。`dictate` 使用经核对的 `dict·ate` 关联。

0.4.0 学习页直接展示“理解、关联记忆、例句”三块内容：机构释义与词性保持主位，理解说明压成一行；关联记忆优先显示可靠的拆记、词义辨析、词族和词形，不再展示机械的中文词义归组。永久易忘清单与每日间隔复习已经分离。

这是一个无需自有服务器即可运行的微信小程序体验版。51份机构词表共2522条来源记录已内置在安装包中，学习状态、复习时间和每日统计保存在当前手机的微信本地存储。

## 当前学习流程

1. 到期复习：先处理已经到期的词。
2. 新词建联：每天按机构顺序引入50条来源记录；全部2522条均包含音标、分包离线发音、词性、机构释义、中英例句及记忆辅助。可确认的词族、词形变化与易混辨析按词显示，不为凑齐栏目编造词根。
3. 逐词过关：选择“没想起”或“部分想起”的词持续进入强化，直到独立回忆成功。至少隔60秒再测，优先穿插其他词；可以随时退出后继续。
4. 延迟抽测：有已校对语境题的多义词使用客观选项，作答后显示整句翻译和解析。

基础任务完成后，可按25词继续加量到75或100词；每日上限100词。加量只会继续取机构词表中的下一条，不会打乱机构顺序。

“部分想起”适用于只想起部分义项、需要较长时间、或主要方向对但不够确定的情况。正常认识MEM阅读中的主要词义时选择“主要义想起”；只有快速、完整且确定时才选择“秒答完整”。

## 导入微信开发者工具

1. 安装并登录微信开发者工具。
2. 选择“导入项目”，项目目录选择本文件夹。
3. 核对项目 AppID 与自己的小程序一致。不要把AppSecret写进项目文件。
4. 在模拟器中编译，使用“预览”可以先在iPhone扫码检查。
5. 点击“上传”，填写版本号与说明。
6. 在微信公众平台把该版本设为体验版，并将自己的微信号加入体验成员。

第一次打开体验版需要网络下载小程序包。词表和学习逻辑不访问外部接口，下载完成后在网络不稳定的地铁中仍可学习；如果尚未进入小程序界面就停在微信的“连接中”，这是微信客户端在冷启动、校验或恢复体验包，并非学习页正在请求服务器。微信清理缓存、体验版更新或语音分包尚未缓存时，仍可能需要网络，因此建议进站前先打开一次并准备好发音。

## 0.3.0：全词库辅助学习

- **发音**：全量合成美式女声，2514个音频覆盖2522条记录（重复拼写共享音频），分成12个语音包。更新后先在“词库”点“下载全部发音”，完成后再进入无信号环境。首次点某个词也会自动准备对应分包。微信清理缓存或版本更新后可能需要重新下载。
- **例句**：显示答案后再展示简短英文场景和中文翻译，避免回忆前泄露词义；机构释义仍是记忆目标。例句由自编内容和有署名的Tatoeba语料组成，来源见各例句及 THIRD_PARTY_NOTICES.md。
- **主动复习**：首页可练最近50个已学词；词库可练指定机构日的已学词，也可从永久易忘清单中主动复习。可中断再继续；记录单独保存，不改变卡片的到期日、间隔、原定每日完成情况或未来任务。正式学习进度同时保留。
- **按天词库**：核心9天、高频42天共51组，可查看各日已学数量，进入单词列表或直接主动复习。仍按机构顺序排列。
- **记录兼容**：继续使用原有卡片ID；状态结构升级到schemaVersion 3，旧记录和旧备份会自动迁移，并把旧版当前可见的易忘词带入永久易忘清单。

语音为机器合成，不等于真人词典录音；多音词的单独读音可能无法覆盖所有词性。发现读音或例句不合适可按单词来源编号反馈。释义未被例句数据替换。

## 0.3.2：内容覆盖与语音加载修正

- 全词库增加词典支持的词性和记忆辅助；核心第2天补充50条针对性理解与关联提示，保留第1天的精编提示。其他词结合词典、已确认的词族或例句场景辅助回忆，并非全部人工精编。没有可靠关联的词不强行拆词。
- 中文内容统一转为简体。长例句署名收进可点击的“例句来源与说明”，保留作者、句子编号及许可；机构释义仍是主要记忆目标。
- 语音文件共8,867,160字节，约8.9 MB，分12包；单包约0.3–0.8 MB。使用小程序跨分包异步加载，不再使用小游戏的加载接口。支持移动网络和Wi-Fi；点播放会按需准备对应小包，无需先下载全部。中断可重试，并显示具体错误。缓存由微信管理，不能保证被清理后仍可离线播放。
- 不改卡片ID、学习顺序、存储键或记录结构；升级不主动清除学习记录。

- 当天每个待学/待复习词都必须成功回忆一次，语境题也需答对，才显示完成。通过指回忆主要义或快速完整回忆；不等于长期掌握。语境题重试调整选项位置，不额外编造题目。
- 连续答错会持续保留任务；跨天、退出、备份恢复后仍保留未通过标记。旧版未完成会话可继续，历史完成日不重算。
- 当天发生遗忘、部分想起或语境错误的词，通过后最晚次日复习；同一天成功重复不再放大间隔。后续按已有间隔算法继续安排。这是保守的产品规则，不宣称60秒或次日是所有词的最佳间隔。

- 主动复习继续独立保存，不改变正式任务和间隔。
- 学习卡片单独滚动，作答按钮保留在底部安全区域；默认只展示机构释义、简短针对性提示和例句。重复例句的通用语境说明不展示，理解补充、词族、易混、词形及来源放在“更多记忆帮助”中。

## 0.4.0：关联记忆与永久易忘清单

- “理解”只补一句简短中文解释；“关联记忆”按词显示拆记、针对性助记、近义/易混辨析、词族和词形，例句保持独立展示。没有可靠词源时只标为拼写分段，不把字形巧合解释成构词来源。
- 永久易忘清单不会因间隔拉长或答对而自动移除。正式学习选“没想起”、连续两次选“部分想起”或语境题答错会自动加入，也可以在学习页或词库中手动加入、移出。
- 永久易忘清单只服务于用户主动复习，不参与每日到期任务的生成；主动复习结果也不会改变正式卡片的复习日期。每日复习仍由卡片的到期时间和未过关状态决定。
- 修复“易忘 → 按天查看 → 选择某天”后筛选条件被重置为全部的问题。

## 备份操作

0.3.1 修复导出失败提示：导出后需再点“发送备份文件”；文件生成不代表已经备份到小程序外。分享失败会显示具体原因，也可复制完整备份文本粘贴到备忘录保存，随后通过“用备份文本恢复”导入。文本备份须完整保留，不要编辑或截断。剪贴板不算长期备份。

- “进度 → 导出备份”会生成带版本信息的JSON备份文件，可发送到自己的文件传输助手。
- “进度 → 恢复备份”可以选择之前的JSON文件恢复。
- 0.1.x版备份可自动迁移到当前数据结构；程序升级时也会先保留一份迁移前记录。
- 恢复操作会覆盖当前手机的学习进度，并在操作前二次确认。
- 不要清除微信小程序数据；更换手机前先导出备份。

## 数据校验

在项目根目录运行：

```powershell
node tests/core.test.js
node tests/features.test.js
node tests/backup.test.js
node tests/content.test.js
node tests/mastery.test.js
```

测试会校验词库数量、唯一来源编号、缺号保留、基础复习间隔、每日50条新词和语境题结构。

扩展测试还校验主动复习的调度隔离、两套会话保存、旧记录兼容、全量例句音标音频、分包大小及下载重试。内容构建依次运行 `scripts/build-learning-content.py`、`scripts/build-memory-aids.py`、`scripts/build-associations.py`；最后一步是原子质量门禁，任何单词缺少完整拼写拆记或有效的“字母/读音→词义”路径都会终止构建，并且不会改写运行包。第二步使用构建依赖 OpenCC 转简体。语音构建：`scripts/generate-piper-audio.py`。构建用模型、依赖及语料在忽略目录 `scripts/work`，不会上传到小程序。
