# 词序微信小程序

这是一个无需自有服务器即可运行的微信小程序体验版。51份机构词表共2522条来源记录已内置在安装包中，学习状态、复习时间和每日统计保存在当前手机的微信本地存储。

## 当前学习流程

1. 到期复习：先处理已经到期的词。
2. 新词建联：每天按机构顺序引入50条来源记录；首批50词包含音标、离线发音、机构释义、理解提示、词形关联与易混辨析。
3. 难词强化：选择“没想起”或“部分想起”的词会在若干张卡片后再次出现。
4. 延迟抽测：有已校对语境题的多义词使用客观选项，作答后显示整句翻译和解析。

基础任务完成后，可按25词继续加量到75或100词；每日上限100词。加量只会继续取机构词表中的下一条，不会打乱机构顺序。

“部分想起”适用于只想起部分义项、需要较长时间、或主要方向对但不够确定的情况。正常认识MEM阅读中的主要词义时选择“主要义想起”；只有快速、完整且确定时才选择“秒答完整”。

## 导入微信开发者工具

1. 安装并登录微信开发者工具。
2. 选择“导入项目”，项目目录选择本文件夹。
3. 将项目配置中的 `touristappid` 换成你的小程序 AppID。不要把AppSecret写进项目文件。
4. 在模拟器中编译，使用“预览”可以先在iPhone扫码检查。
5. 点击“上传”，填写版本号与说明。
6. 在微信公众平台把该版本设为体验版，并将自己的微信号加入体验成员。

第一次打开体验版需要网络下载小程序包。词表和学习逻辑不访问外部接口，下载完成后在网络不稳定的地铁中仍可学习；如果线路存在完全无信号区间，建议进站前先打开一次小程序，避免微信在冷启动时需要联网校验。

## 本地数据

- “进度 → 导出备份”会生成带版本信息的JSON备份文件，可发送到自己的文件传输助手。
- “进度 → 恢复备份”可以选择之前的JSON文件恢复。
- 0.1.x版备份可自动迁移到当前数据结构；程序升级时也会先保留一份迁移前记录。
- 恢复操作会覆盖当前手机的学习进度，并在操作前二次确认。
- 不要清除微信小程序数据；更换手机前先导出备份。

## 数据校验

在项目根目录运行：

```powershell
node tests/core.test.js
```

测试会校验词库数量、唯一来源编号、缺号保留、基础复习间隔、每日50条新词和语境题结构。
